# Matix the Math Club — native Android source

This is the Kotlin + Jetpack Compose Android Studio project. It is source-only:
no APK or Android App Bundle is included or generated by this handoff.

## Open and run in Android Studio

1. Extract the project and open the `Matix-the-Math-Club-Android` folder in Android Studio.
2. Allow Gradle sync to finish. Use JDK 17 and the Android SDK required by the project (`compileSdk 34`, `minSdk 26`).
3. Select an emulator or connected device and press **Run**.
4. For a Play Store bundle, use **Build → Generate Signed Bundle / APK → Android App Bundle** and select your own upload key. The Gradle project no longer silently signs release builds with the debug key.

## Native app notes

- The app screens use Kotlin and Jetpack Compose; club-made HTML games and owner-uploaded HTML pages run in Android WebViews with file/content access disabled. HTML game code still runs JavaScript, so only play content from sources you trust.
- Math Learn's **Learn anything** feature uses the Python service referenced by the supplied `app.html` (`server/matix_learn_server.py`); that service was not part of the Android ZIP. For an Android emulator, the usual host URL is `http://10.0.2.2:8787`. On a physical phone, use a reachable HTTPS URL in **Learn → Server**; plain HTTP is enabled only for the local emulator hosts above. If the service is offline, previously cached Firebase lessons can still load.
- Matix AI needs an API key entered in **Settings**. The native assistant supports tool calls; shared posts, game publishing, and owner actions ask before writing.
- The legacy Firebase Realtime Database layout is retained for compatibility with the HTML app. Review its security rules and migrate the legacy client-side password scheme before distributing publicly. No built-in member passwords were copied into the Android code.

## Current parity status

The port includes the native welcome/sign-in shell, home hub, game builder/edit/play, ideas, translation, profile/theme preferences, points and requests, notifications, Math Chat/Discussions, private notes and to-dos, custom owner pages, and the Math Learn path/editor/practice/quests/tests/shop/badges/leaderboard and Learn-anything client.

It is not a claim of pixel-identical or complete feature parity. Some web-only behavior still needs device QA and/or a separate backend port (including live video calls, every original AI workflow and file attachment, complete UI translation/localization, and the HTML app's exact interaction/animation details). Test against the original `app.html` on a device before treating this as a 1:1 release.
